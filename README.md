## 🛠️ Technical Skills

### 🐧 Linux Administration
- **Distributions:** Debian, Ubuntu Server, RHEL / CentOS / Rocky Linux.
- **Services & Networking:** Apache, Nginx, DNS (Bind9), DHCP, Postfix, Samba, NFS, SSH.
- **Security & Firewalls:** UFW, IPTables, Firewalld, Fail2Ban, permissions management, system hardening.
- **Management & Storage:** LVM, software RAID, Systemd, Cron, log analysis (`journalctl`, `grep`, `awk`, `sed`).

### 🪟 Windows Server Administration
- **Systems:** Windows Server (2016, 2019, 2022).
- **Infrastructure Services:** Active Directory (AD DS), Group Policy Objects (GPO), DNS, DHCP, WSUS, IIS.
- **Virtualization & Storage:** Hyper-V, file share management (DFS, NTFS permissions), backups.
- **Windows Scripting:** PowerShell (automated account creation, AD audits, maintenance).
